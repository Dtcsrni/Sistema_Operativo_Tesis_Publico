La investigación desarrolla una arquitectura resiliente para telemetría y control adaptativo en entornos urbanos intermitentes. El repositorio SIOT funciona como infraestructura de gobierno, trazabilidad, operación y escritura científica para sostener el avance del proyecto con evidencia verificable.

El borrador actual prepara la transición hacia un documento revisable por terceros. Su énfasis inicial es metodológico: describir cómo el sistema coordina agentes de IA diversos mediante una capa de harness engineering agnóstica, reproducible y subordinada al control humano.
